How it works

One shared state, four questions, one rule each

The three players share a GHZ state, (|000> + |111>) / √2, made once before they split up. A referee picks one of four rounds and tells each player to measure in the X basis or the Y basis. Each sends back one bit. The team wins if the three answers multiply to the round's target.

The four rounds

RoundABCAnswers must multiply to
1XXX+1
2XYY−1
3YXY−1
4YYX−1

The quantum team meets all four with certainty, because the GHZ state is a +1 eigenstate of XXX and a −1 eigenstate of the other three.

Why a classical team cannot win all four

Suppose each player decided both answers in advance. Multiply the left side of all four rules together. Every player's X answer and Y answer each appear twice, so everything squares to +1.

Left sides multiply to +1. Right sides multiply to (+1)(−1)(−1)(−1) = −1.

So a fixed plan would need +1 = −1. Impossible. The best any classical team can do is satisfy three of the four, which is 75 percent. Entanglement is not sending a message here, it is sharing a correlation no pre-agreed plan can fake.

What you are seeing

Each toggle sets a predetermined answer, exactly what a classical team is limited to. Green means that round's rule is met, red means it is broken.

Shared randomness does not help. It is only a mixture of fixed plans like this one, so it cannot beat the best fixed plan. The quantum team sidesteps the whole argument because its answers are not predetermined, they are created by measurement.

The Qiskit circuit

from qiskit import QuantumCircuit

def ghz():
    qc = QuantumCircuit(3)
    qc.h(0)
    qc.cx(0, 1)
    qc.cx(0, 2)      # (|000> + |111>) / √2
    return qc

# round "XYY": player A measures X, B and C measure Y
qc = ghz()
qc.h(0)              # X basis
qc.sdg(1); qc.h(1)   # Y basis
qc.sdg(2); qc.h(2)   # Y basis
qc.measure_all()     # answers must multiply to -1
